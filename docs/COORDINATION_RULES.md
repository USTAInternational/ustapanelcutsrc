# Правила координационной модели

`ProjectCalculation.assembly` — единственный источник координат для 3D,
фасадов, разрезов и ведомостей. Расчётная единица — миллиметр.

## Система координат и уровни

- X направлена вдоль длины здания, Z — вдоль ширины, Y — вверх.
- `Y = 0` является верхом фундамента.
- Фундамент занимает только диапазон `foundationBottomMm <= Y <= 0`.
- Опорная плита начинается на `Y = 0`; колонна начинается на её верхней грани.
- Локальная геометрия поверхности переводится в проектные координаты только
  через её `SurfaceFrame` (`origin`, `uAxis`, `vAxis`, `normal`).

## Панели и узлы

- `blankPolygon` описывает производственную заготовку.
- `installationPolygon` описывает панель после монтажных подрезок.
- Технологические пустоты являются объектами `ConstructionVoid`; отсутствие
  материала не имитируется прозрачностью или взаимным наложением панелей.
- Каждый фасонный элемент является `FlashingInstance` с маркой, профилем,
  траекторией, длиной, нахлёстом и количеством заготовок.
- Итоговые погонные метры и стоимость рассчитываются из экземпляров, а не из
  независимых формул представления.
- При горизонтальной раскладке продольный фасад сначала делится по фактическим
  осям колонн. Производственная длина панели равна расстоянию между соседними
  осями; `supportSpan.visibleLengthMm` дополнительно вычитает видимую ширину
  угловых планок и половины межколонных нащельников.
- Крайняя панель получает монтажный выпуск за угловую ось из
  `external-corner.panelExtensionMm`; производственная длина с выпуском хранится
  в `supportSpan.fabricationLengthMm`.
- На каждой внутренней оси продольного фасада создаётся узел
  `transverse-seam` и отдельный фасонный элемент `FE-TS`.

## Допустимые контакты

- Разрешены: колонна–опорная плита, опорная плита–фундамент,
  панель–фасонный элемент, панель–уплотнение.
- Запрещены: колонна–объём фундамента, панель–объём колонны.
- Нарушения не исправляются скрытно. Валидатор возвращает ID объектов,
  серьёзность и поверхность для перехода между 2D и 3D.

## Статус каталога

Координационные размеры в `jointRules.ts` имеют статус `verified: false`, пока
для серии панели не приложены документ производителя и его редакция. Такая
модель доступна для эскизного просмотра, но `documentationBlocked` остаётся
включённым, а PDF получает отметку «ЭСКИЗ».
