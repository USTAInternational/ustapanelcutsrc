# Калькулятор раскладки сэндвич-панелей

Одностраничное браузерное приложение для предварительной раскладки стеновых и кровельных панелей прямоугольного здания. Расчеты выполняются локально в миллиметрах, backend не требуется.

## Запуск

```bash
npm install
npm run dev
npm run typecheck
npm run test
npm run build
```

## Архитектура

- `src/domain` — строгие типы и исходный проект.
- `src/geometry` — чистые функции поверхностей, clipping, раскладки и проемов.
- `src/calculation` — единый расчет проекта, группировка, площади, стоимость и предупреждения.
- `src/store` — Zustand и LocalStorage.
- `src/components` — формы, SVG, 3D, ведомость и итоги.
- `src/export` — JSON, CSV, SVG и PDF.

Расчетный результат `ProjectCalculation` является единым источником для SVG, 3D, ведомости и экспорта. Размеры внутри ядра хранятся в мм, площади — в мм².

## Ограничения

Поддерживаются прямоугольный план, плоская, односкатная и симметричная двускатная крыша. Панели, превышающие максимальную длину, помечаются предупреждением и автоматически не разделяются. Расчет не проверяет несущую способность и не заменяет проектную документацию.
